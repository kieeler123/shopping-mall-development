# 문제·정답 — 2026-10-29

### 1. CartItem과 OrderItem을 왜 구분할까?

**정답:** 주문 당시 상품명과 가격을 보존하기 위해서다.

### 2. Effect 안의 동기 setState는 왜 문제일까?

**정답:** 추가 렌더링과 린트 오류를 유발할 수 있다.

### 3. 스냅샷을 문자열로 반환하는 이유는?

**정답:** 매번 새 배열을 반환하면 참조가 불안정하기 때문이다.

### 4. 같은 탭의 저장소 변경을 어떻게 알릴까?

**정답:** cart-updated 또는 orders-updated 이벤트를 발생시킨다.

### 5. 주문 당시 가격을 사용하는 이유는?

**정답:** 상품 가격이 바뀌어도 과거 주문을 정확히 유지하기 위해서다.

### 6. AbortController의 역할은?

**정답:** 필요 없는 요청을 취소하고 오래된 응답 반영을 방지한다.

### 7. 메인 화면 중복의 직접 원인은?

**정답:** layout.tsx의 children 두 번 렌더링이다.

### 8. 링크 글자색 문제의 원인 후보는?

**정답:** 전역 a 색상 규칙과 Tailwind의 우선순위 충돌 가능성이다.
