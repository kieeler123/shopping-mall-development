# 문제·정답 — 2026-10-29

### 1. なぜCartItemとOrderItemを分ける？

**解答:** 注文時の商品名と価格を保存するため。

### 2. Effect内の同期setStateの問題は？

**解答:** 追加レンダリングやLintエラーの原因になる。

### 3. 文字列スナップショットの理由は？

**解答:** 毎回新しい配列を返すと参照が不安定になるため。

### 4. 同じタブの変更を通知するには？

**解答:** カスタムイベントを発行する。

### 5. 注文時の価格を使う理由は？

**解答:** 過去の注文金額を正しく保持するため。

### 6. AbortControllerの役割は？

**解答:** 不要なリクエストを中止する。

### 7. 画面重複の直接原因は？

**解答:** layout.tsxのchildrenの二重描画。

### 8. リンク文字色の原因候補は？

**解答:** グローバルCSSとTailwindの競合の可能性。
