# Day 24 --- `useEffect`と外部システムとの同期

## 重要な質問

> コンポーネントはいつ外部システムと同期するのか？

## 学習テーマ

``` text
render
Effect
useEffect
dependency array
外部システム
API呼び出し
```

## 重要な概念

`useEffect`を単純に次のように覚えない。

``` text
useEffect = fetch
```

代わりに、次のように理解する。

``` text
useEffect
=
Reactコンポーネントを
外部システムと同期するための仕組み
```

外部システムの例：

``` text
API
サーバー
ブラウザAPI
タイマー
イベントリスナー
外部ライブラリ
ネットワーク接続
```

> **ポイント:**
> `useEffectの中で何をするか？`より先に、`Reactの外部にある何と同期するのか？`を考えます。

------------------------------------------------------------------------

## 基本的な流れ

``` text
コンポーネントをレンダリング
↓
Effect実行
↓
外部システムと同期
↓
API呼び出し
↓
データ取得
↓
State更新
↓
再レンダリング
↓
UI更新
```

> **ポイント:** Day 23の`Event → State → UI`と、Day
> 24の`Render → Effect → External System → State → UI`を比較します。

------------------------------------------------------------------------

## renderとEffectの違い

### render

現在のPropsとStateをもとに、UIをどのように表示するかを計算する処理です。

``` text
Props + State
↓
コンポーネント実行
↓
JSX計算
↓
UI
```

### Effect

レンダリングそのものではなく、Reactの外部にあるシステムと同期するための処理です。

``` text
レンダリング
↓
Effect
↓
外部システムとの同期
```

> **ポイント:**
> UIを計算する処理なのか、Reactの外部と接続する処理なのかを区別します。

------------------------------------------------------------------------

## 基本的な`useEffect`

``` tsx
useEffect(() => {
  console.log("Effect実行");
}, []);
```

基本構造：

``` tsx
useEffect(() => {
  // Effectの処理
}, [dependencies]);
```

2番目の引数を**依存配列（dependency array）**といいます。

> **ポイント:**
> 文法を暗記する前に、`いつ再び同期する必要があるのか？`を考えます。

------------------------------------------------------------------------

## Dependency Array

``` tsx
useEffect(() => {
  // ...
}, [value]);
```

Effectが使用しているリアクティブな値が変化すると、再び同期が必要になる場合があります。

次のようにだけ暗記するのではなく：

``` text
[] = 1回
[value] = valueが変わったとき
```

次の質問をします。

``` text
このEffectはどの値に依存しているのか？
```

> **ポイント:** 依存配列とEffect内で使用する値を関連付けて理解します。

------------------------------------------------------------------------

## API呼び出しとEffect

``` tsx
useEffect(() => {
  void loadOrders();
}, [loadOrders]);
```

このコードの流れ：

``` text
コンポーネントをレンダリング
↓
Effect実行
↓
loadOrders()実行
↓
外部APIと通信
↓
注文データ取得
↓
State更新
↓
再レンダリング
↓
注文UI更新
```

> **ポイント:**
> `useEffect = API呼び出し`ではなく、`APIは外部システムなのでEffectで同期する`と理解します。

------------------------------------------------------------------------

## 実際のプロジェクトとのつながり

``` tsx
useEffect(() => {
  void loadOrders();
}, [loadOrders]);
```

本質は：

``` text
Reactコンポーネント
↕
外部システム
```

の間を**同期すること**です。

API呼び出しは外部システムとの同期の一例にすぎません。

> **ポイント:**
> プロジェクトコードでは、`loadOrders()`が最終的にどのStateを更新するのかも追います。

------------------------------------------------------------------------

## Day 24の最終目標

次のコードを見たとき：

``` tsx
useEffect(() => {
  void loadOrders();
}, [loadOrders]);
```

次のように説明できることが目標です。

``` text
コンポーネントをレンダリング
↓
Effectが外部システムとの同期を行う
↓
loadOrders()で注文データを取得
↓
データをStateに反映
↓
State更新によって再レンダリング
↓
新しい注文データをUIに表示
```

> **ポイント:** Day
> 24で最も重要なのは、**なぜその処理をrenderではなくEffectで行う必要があるのか？**を考えることです。
