## 오늘의 핵심 용어 흐름

``` text
State → setter → updater → prevOrders
                 ↓
      spread / map / filter
                 ↓
            새로운 배열
                 ↓
            State 업데이트
                 ↓
              재렌더링
                 ↓
             JSX → UI
```

**팁:** 용어를 따로 외운 뒤 마지막에는 이 흐름을 보면서 각 용어를 서로
연결해 설명한다.
