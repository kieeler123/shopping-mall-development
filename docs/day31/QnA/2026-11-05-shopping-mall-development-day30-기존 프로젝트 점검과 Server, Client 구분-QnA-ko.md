# Day 31 — 문제·답변
> 기존 프로젝트 점검과 Server / Client 구분

**학습일:** 2026-11-05  |  **계획 학습 시간:** 120 min  |  **Score:** 94/100 (PASS)

## 1. Route Handler와 Client Component의 차이는?
정답 B: Route Handler는 HTTP 요청·응답을 처리하고 Client Component는 사용자 상호작용을 담당한다. 실제 제출 정답 B, 20/20점.

## 2. 서버에서 localStorage를 읽으면 왜 안 되는가?
서버에는 브라우저 localStorage가 존재하지 않는다.

## 3. "use client"면 모든 코드가 브라우저에서만 실행되는가?
아니다. 초기 서버 프리렌더링이 가능하므로 렌더링 중 브라우저 API 접근에 주의한다.

## 4. useSyncExternalStore의 목적은?
외부 저장소 구독 및 서버/클라이언트 스냅샷 관리.

## 5. 주문 스냅샷이 필요한 이유는?
상품명과 가격이 나중에 바뀌어도 주문 당시 정보를 보존하기 위해서다.

## 6. storage 이벤트가 같은 문서에서 발생하는가?
변경을 수행한 문서에는 발생하지 않는다. 별도 사용자 정의 이벤트를 활용한다.

## 7. 관리자 주문과 사용자 주문은 연결되어 있는가?
현재 확인한 코드에서는 연결되어 있지 않다. 관리자 API 경로 파일도 없다.

## 8. 주문 완료 페이지의 한계는?
orders[orders.length - 1]은 마지막 저장 주문이지 반드시 방금 완료한 주문은 아니다.
